## 🚀 About Me

- 🎓 Pursuing a dual-degree **B.Tech & M.Tech in Computer Science and Engineering** at **IIITDM Kancheepuram**.
- 🚁 **Software Lead** at **Team Astra**, architecting autonomous UAV systems, VIO pipelines, and obstacle avoidance algorithms.
- 🤖 Researching **Machine Learning & Signal Processing**, engineering end-to-end pipelines for bio-signal feature extraction (ECG/IMU), sensor fusion, and real-time classification.
- 🧠 Building and fine-tuning **Deep Learning models** using **PyTorch & Scikit-Learn** for edge deployment, computer vision, and predictive analytics.
- 🎮 Building immersive 3D gameplay mechanics in **Unreal Engine 5 (UE5)** using C++ and modular Blueprints.
- 💻 Experienced in full-stack web applications (**Next.js, React, Flask, Supabase, PostgreSQL**) and systems engineering (**C/C++, ROS, Linux**).
